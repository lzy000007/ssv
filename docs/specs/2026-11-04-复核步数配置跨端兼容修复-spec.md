# 复核步数配置跨端兼容修复规格

## 问题与目标

提交 `52341d3` 为 Python Agent 和共享配置模板增加了 `agent.review.recursion_limit`，但原生 runner 的 `validate_review_extension` 未允许该键。使用模板启动 runner 会在配置阶段返回退出码 2；即使 `agent.review.enabled=false` 也无法启动。

本次补齐原生配置校验，使共享模板和显式设置执行预算的本地配置均可用于检测与 Agent 运行。

## 配置契约

- `agent.review.recursion_limit` 可省略，实际执行预算继续由 Python Agent 使用默认值 256。
- 显式配置时使用 YAML 正整数；原生侧沿用既有整数读取和错误分类方式。
- 0、负数返回 `InvalidValue`；布尔值、浮点数、字符串、null、列表和映射返回 `InvalidType`，错误路径均为 `agent.review.recursion_limit`。
- 复核开关关闭时同样校验字段，保留共享配置对未知键和无效值的严格检查。
- C++ 仅验证该 Python 扩展字段，不新增配置成员或执行预算的持有方。Python 的默认值、服务装配和 LangGraph 参数传递保持原有方式。

## 验收

- 原生配置测试能够读取现有 `config/ssv.example.yaml`，并覆盖复核开关两种状态下的省略、合法值和非法值。
- 重新编译原生 runner，运行相关 C++ 测试和 Python Agent 全量回归。
- 使用显式包含 `recursion_limit: 256` 的临时配置完成本地视频检测及 Agent 任务流转，核对结果和退出状态；测试使用隔离的 Redis 流、账本及输出路径。
- 原始模型结论与人工核对分别记录，不将配置兼容修复表述为视觉误判已修复。

- 不修改生产配置、既有数据和历史结果，不提交、推送或暂存变更。
- 不新增永久运行脚本；临时运行文件与未引用缓存结束后清理，正式证据和报告保留。
