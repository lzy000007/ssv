# 项目监测作业区域安全帽佩戴规则

## 原始依据与性质

本项目用户于 2026-11-02 在自动审核配置会话中明确确认本规则：监测作业区域内人员必须佩戴安全帽，清晰视频中可确认未佩戴即判违规、正确佩戴即判合规；遮挡或画面不足时继续自动取证，仍无法判断则保留证据不足，不强行判定。

本规则登记为项目现场规则，标识为 `SSV-SITE-HELMET-20261102`，适用于显式绑定 `site-helmet/v1` 且登记 `helmet_required_area=confirmed` 的监测作业区域。该依据来自项目用户的明确确认，不宣称出自国家标准，不要求电力作业方式、标准适用性或帽体绝缘性能事实。

## 1.1 自动审核要求

人员进入上述监测作业区域应正确佩戴安全帽。登记事实确认区域要求后，以本事件的可用视频、图片及合法采样画面逐项判断实际佩戴状态。

当至少一名区域内人员与清晰完整头部可关联，且画面明确显示该人员未佩戴安全帽时，判定 `violation`。确认头部裸露即可证明未佩戴，不需要同时存在 `head` 或 `helmet` 检测标签，也不要求检测轨迹已经确认。普通便帽、手持安全帽或旁边放置安全帽不能作为正确佩戴依据。

当本次事件范围内全部相关人员的头部与佩戴关系均可核验，且均正确佩戴安全帽时，判定 `compliant`。不能仅凭没有检出违规、没看到头部或没看到帽子判定合规。

## 视觉证据与证据不足

人物位置、服装和连续画面可以用于建立人员与头部的对应关系。专用检测标签和轨迹只提供候选信息，不能代替视觉核验；缺少这些标签本身也不否定清晰的视觉事实。

采样画面为近似时间定位时，可以支撑其中清晰可见的事实，但不得宣称是检测时刻的原始检测帧。粗采样不足以判断时，应对合法相对时间窗口精采样；遮挡、模糊、目标过小、对象关联不清或相关时段实际未覆盖且进一步采样仍不能解决时，保持 `uncertain`，说明具体缺项。

结论只覆盖本事件中上述安全帽佩戴义务，不扩展到安全带、护目镜、产品认证、绝缘性能或画面外时段。其他规则的额外作业前提不能作为本规则的附加要求。
