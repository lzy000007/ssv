# 特定带电作业法的绝缘安全帽要求

## 原文依据

以下文字按仓库留存的 GB 26860—2011 第 9.2.11 条合并换行转录，保留原文作业法前提。原始文件为 `agent/knowledge/GB+26860-2011 (1).md`；现场使用须核对适用规程原件，本摘录不认证标准现行性。

9.2.11 采用绝缘手套作业法或绝缘操作杆作业法时,应根据作业方法选用人体绝缘防护用具,使用绝缘安全带、绝缘安全帽。必要时还应戴护目眼镜。工作人员转移相位工作前,应得到工作监护人的同意。

## 适用条件

依据已核对且标准适用范围已确认，并有证据证明采用绝缘手套作业法或绝缘操作杆作业法，才能使用本规则。对应 `rule_facts` 为 `rule_basis_verified=confirmed`、`gb26860_2011_applicable=confirmed` 和 `work_method=insulating_glove` 或 `insulating_operating_rod`。事实值仍须通过登记证据逐项核验。

普通工地、非上述作业法或作业方式不明，均不能仅靠本条得出确定性结论。缺少适用事实时应输出 `uncertain`，不把“不适用”解释为“合规”。

## 业务解释

本复核仅针对原文中的安全帽子要求：上述作业前提成立且清楚观察到未戴任何安全帽时，可支持无帽违规。安全带、护目眼镜及转移相位许可等原文义务另有要求，本规则不据安全帽画面宣称整条规定均已合规。

## 可观察证据与无法判断条件

`head`、`helmet`、检测置信度和轨迹只提示候选，不能代替查看证据。完整头部不可见、遮挡、模糊、小目标、人与帽关联不明、检测冲突或相关作业时段缺失时，应输出 `uncertain`。手持安全帽不能证明佩戴；未发现违规不能自动认定合规。

仅看到帽体不能核验绝缘性能。绝缘安全帽合规还须有 `helmet_insulation=verified` 及与该人员帽体对应的登记证据；仅有普通视频且没有性能依据时，输出 `uncertain`。不得根据颜色、外形或普通安全帽类别猜测性能。
