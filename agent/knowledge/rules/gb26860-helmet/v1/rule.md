# 作业现场安全帽佩戴复核示例

## 原始依据与性质

本文件是项目内部业务示例，没有已核验的国家标准原文或已发布现场制度作为依据。`gb26860-helmet/v1` 仅保留既有引用身份，不表示本条来自 GB 26860。项目示例不能支撑 `compliant` 或 `violation` 确定性结论。

## 业务解释

1.1 在已有现场制度明确要求佩戴安全帽的作业区域，可复核人员是否正确佩戴安全帽。实际使用应提供现场制度原文、出处、适用范围及证据；本示例本身不授予该制度效力。

## 适用条件与视觉边界

`helmet_required_area=confirmed` 必须有登记证据，不能由 `head` 标签、摄像头名称或普通“安全帽”问题推断。检测只产生待核验候选，不能直接判定违规。

头部遮挡、画面模糊、目标过小、人与帽无法关联、检测冲突或相关时段未覆盖时，应输出 `uncertain`。未发现违规不等于确认合规；手持安全帽不等于佩戴。画面中的普通帽体不能证明绝缘性能或产品合格性。
